# 蛍草キャラクターLoRA 学習開始条件

## 現状

- 利用可能な独立した原作画像は1枚。
- 生成画像は誤った髪型・衣装を含むため、学習元には使用しない。
- 現時点で再学習すると、1構図の過学習と誤特徴の固定化が避けられない。

## 学習開始条件

- 出所を記録できる鮮明な原作画像を最低12枚、推奨20枚以上用意する。
- 正面、斜め、横、上半身、全身を含め、同一画像の切り抜きだけで水増ししない。
- 髪、リボン、髪飾り、目、襟、袖、帯が確認できる画像を含める。
- UI、検索表示、透かし、大きな文字、他キャラクターが重なる画像を除外する。
- 近重複を同一グループとして扱い、学習と検証へ分割して漏洩を防ぐ。

条件を満たした後、画風LoRAとは別のキャラクターLoRAとして学習・評価する。
